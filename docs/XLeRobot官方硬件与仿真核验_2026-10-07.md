# XLeRobot 官方硬件与仿真核验（2026-10-07）

适用设备：用户已确认 **XLeRobot 0.4、双轮差速、12V**。本次核验的是官方网页和官方源码；未安装依赖、未运行仿真、未连接或驱动实机。电机具体型号、供电端口输出和已配置 ID 尚未通过实物确认。

## 1. 版本标签与硬件路线

官方 Read the Docs 页眉仍显示 `XLeRobot 0.3.0 documentation`，但双轮装配页正文明确描述 **0.4.0**；所以不能把 `latest` 的页眉当作所有章节的硬件版本。该页仍标注施工中，并列出舵机和无刷电机两条路线；无刷路线写明仍在开发。对用户设备优先参考双轮章节，具体电机路线仍需对照实物。[官方首页](https://xlerobot.readthedocs.io/en/latest/index.html)、[双轮装配](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/assemble_2wheel.html)

官方将双轮版相较三全向轮的稳定性、速度、通过性和扭矩改善作为设计说明，未给出统一测试条件或量化对比。差速底盘可前后移动、转向，不能直接横移；这与旧全向底盘的控制和数据维度不同。[双轮源码说明](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/software/src/robots/xlerobot_2wheels/README.md)

## 2. 12V、供电与电机数量

旧 BOM 指定 12V STS3215、两块控制板、两根 12V Type-C 转 DC 线；17 台电机分解为双臂 12、三轮 3、头部 2。该 BOM 仍是三轮配置，不能直接当作用户双轮套件清单。两路 60W 以上 USB-C 是文档建议，替代电源被标注未测试。应确认电源实际能协商输出 12V，以及两路同时供电时的能力，不能仅依据充电宝总功率。[官方 BOM](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/material.html)

按当前双轮源码的电机表推导，舵机版机器人本体是 **16 台电机：双臂 12 + 头 2 + 轮 2**；不包含用于示教的 leader 臂。`12V` 是供电信息，不能单独证明每台实物的型号和齿轮比。[双轮电机定义](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/software/src/robots/xlerobot_2wheels/xlerobot_2wheels.py#L78)

## 3. 电机 ID 与校准不能套用旧底盘章节

当前官方双轮源码规定以下映射；这是软件预期值，不是对用户实物的扫描结果：

| 控制总线 | 部件 | ID |
| --- | --- | --- |
| bus1 / port1 | 左从臂：肩水平、肩抬升、肘、腕弯曲、腕旋转、夹爪 | 1、2、3、4、5、6 |
| bus1 / port1 | 两个头部电机 | 7、8 |
| bus2 / port2 | 右从臂，同上关节顺序 | 1、2、3、4、5、6 |
| bus2 / port2 | 左轮、右轮 | **9、10** |

两块板上重复 1–6 是两条独立总线；同一总线上需唯一。轮子 ID 应以双轮插件对应表为准。老装配页的底盘 7、8、9 是三轮结构。[双轮源码](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/software/src/robots/xlerobot_2wheels/xlerobot_2wheels.py#L78)、[旧装配页](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/assemble.html#configure-motors)

源码将手臂与头设为位置模式、车轮设为速度模式；`setup_motors()` 是逐个改 ID 的写入流程，`calibrate()` 会记录活动范围并写电机。`connect()` 遇到已有校准文件时，默认选择恢复会向电机写校准。故“厂家已经配好”应先与配置文件及实际 ID 对照，不能把这些函数当只读检测。手动校准把轮子的范围设为 0–4095，轮子不按手臂那样记录机械活动范围。[连接与校准](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/software/src/robots/xlerobot_2wheels/xlerobot_2wheels.py#L169)

默认配置为 `port1=/dev/ttyACM0`、`port2=/dev/ttyACM1`、轮半径 **0.05m**、轮距 **0.25m**、`use_degrees=False`，摄像头表默认空。端口和几何参数都是示例，需匹配实物。配置还令 `max_relative_target=None`，不能假设已经启用关节单次位移限制。[双轮配置](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/software/src/robots/xlerobot_2wheels/config_xlerobot_2wheels.py)

## 4. 装配、打印和负载的证据范围

双轮页给出 5 英寸助行器轮、30×37×4mm 轴承、加长电机线，并链接 0.4 的额外打印件；此处只是核实文件存在，没有检查 STL 几何、打印质量或套件零件尺寸。[0.4 STL](https://github.com/Vector-Wangel/XLeRobot/blob/b017b5e6354bd9f61f4247a920c72622ca0aade0/hardware/XLeRobot_0_4_0_extra.stl)

官方打印页说明 3MF 用来存模型，仍需自行安排方向、支撑与切片；软夹指使用 TPU95A。该页轮底座部分依然描述三全向轮，不能原样用于双轮装配。[打印指南](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/3d.html)

装配页要求：接线整理完成后再固定上层结构，延长线核对极性，电源最后接，插拔其它线缆前断电；舵机底盘不宜像普通推车那样强行推动，以免损伤齿轮。这些是文档明确要求。[接线及最终装配](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/assemble.html#wiring)

官方首页列单臂负载 600–1000g、约 40cm 工作范围，但没有提供具体姿态、力矩、持续时间和温升的验证表，不能解释为用户套件全姿态保证值。旧硬件介绍列约 12kg 总重、0.5–1.25m 工作高度、288Wh 电池及长续航描述，属于旧结构和官方声称，不能直接迁移为用户设备实测。[官方首页限制](https://xlerobot.readthedocs.io/en/latest/index.html#limitations)、[硬件介绍](https://xlerobot.readthedocs.io/en/latest/hardware/hardware_intro/index.html)

## 5. 三条仿真路线与双轮适配程度

| 路线 | 已核实资源 | 对用户双轮的意义 |
| --- | --- | --- |
| 网页 MuJoCo + 3DGS | 官方仿真页链接作者的 MuJoCo-GS-Web；其 README 明确 XLeRobot 底盘 2 DOF，W/S 前后、A/D 转向，另有双臂、夹爪与头部控制 | 控制自由度更贴近双轮；未运行，未证实几何、传动和动力学与用户 0.4 完全一致 |
| 官方仓库本地 MuJoCo | `simulation/mujoco/README.md` 指定 MuJoCo 3.3.0，包含横移键和全向底盘控制 | 这是全向示例；不能当已适配双轮的整机模拟 |
| ManiSkill | 官方提供 agent、URDF、ReplicaCAD 环境和关节/末端控制脚本 | 可用于手臂控制和场景实验，但原始 URDF 含虚拟 x、y 平移和旋转关节，未证实真实差速轮接触动力学 |

ManiSkill 安装页要求 Ubuntu，创建 Python 3.11 环境，但后面的示例包路径写 `python3.10`；还要求手动复制 agent/assets/envs 并修改注册与场景文件。这是可辨认的文档路径不一致，应通过当前 Python 的实际安装位置定位，不能照抄固定路径。文档列 ReplicaCAD、AI2THOR、Robocasa、抽屉场景，但没有在本次运行验证。[ManiSkill 入门](https://xlerobot.readthedocs.io/en/latest/simulation/getting_started/index.html)、[更多场景](https://xlerobot.readthedocs.io/en/latest/simulation/getting_started/simdemos.html)

## 6. 对这套设备的执行顺序

以下是依据差异作出的实施建议，不代表已完成：先确认电机型号、供电 12V、两条总线与现有 ID；保存并核对厂家校准；先固定底盘验单臂，再双臂，再让车轮离地低速检查左右轮方向、停止和断连；实际测轮半径与轮距后，才进行地面差速遥操作。仿真可以先用网页版学习双臂和底盘控制，但数据采集、策略迁移仍需匹配实际机器人状态/动作定义。
