## 最容易照搬错的地方

- 文档页眉0.3.0与双轮正文0.4.0不同步；装配旧页和17电机 BOM 是三轮结构。
- 三轮 `xlerobot`、双轮 `xlerobot_2wheels`、双臂 `bi_so_follower` 是不同配置和动作定义。
- 英文安装页采用插件；旧 ACT / 厂家教程仍可能复制文件。不要把两个流程拼成同一个环境。
- 官方 ACT“部署”示例也缺模型路径；这个缺项不能只归因于飞书。新主线部署需实际模型与匹配接口。
- 社区 SmolVLA 的Python3.10/fork示例和当前 LeRobot Python≥3.12主线不能直接混装。
- 双轮不能横移；旧全向仿真、Agent侧移工具和三轮策略不可默认迁移。
- `connect()`可能恢复或写校准；`max_relative_target`默认未启用，其限幅路径有静态疑点。主机watchdog停止的是底盘。
- 400g厂家建议与官方600–1000g说明没有相同测试条件，不应取较大值当作本套件验收承重。

这些差异的具体证据见官方适配报告和厂家教程报告。所有运行参数需以所选代码与实物重新确认。

## 按顺序推进

| 阶段 | 操作 | 通过依据 |
| --- | --- | --- |
| 0 | 盘点两控制板、电机、相机、控制电脑、12V供电与厂家配置 | 设备清单与端口映射完成，配置已备份 |
| 1 | 锁定配套代码与依赖，先做无运动的插件导入/配置核验 | 导入与类型注册通过，记录版本 |
| 2 | 固定底盘，逐关节验证一条从臂的小幅动作与停止 | 方向、范围、夹爪和退出符合预期 |
| 3 | 验证两臂独立识别与双臂遥操作 | 控左不误动右，反之亦然；无互相碰撞 |
| 4 | 轮子离地验证方向与停止，填实测尺寸后地面遥操作 | 前后、转向、松键、退出和断连行为有记录 |
| 5 | 先少量采集检查，再做ACT固定场景任务 | 视频/状态/动作同步，独立评估有成功与失败记录 |
| 6 | 加绘画工装和标定，或按任务选择SmolVLA/π0.5/Agent | 原基线可复现，新功能有完整任务结果 |

当前优先完成阶段0和1所需资料。阶段表是后续计划，不能标为已完成。
