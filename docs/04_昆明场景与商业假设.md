# 昆明场景与商业假设

调研日期：2026-10-02。用户约束：首轮1–5万元；可接触学校、培训、展厅、科研机构，也有文旅资源。以下本地事实来自公开资料，机构尚未接受我们调研或表达采购意向。

## 可核验的本地基础

1. 云南师范大学于2026-05-23在STEM教育中心举办科普体验，官方报道明确出现小型搬运机器人抓取彩色积木。没有型号、底盘结构、成本或采购信息，因此只能证明本地已有机器人科普应用。意味着竞争点应是课程质量与活动交付，而非宣称昆明没有此类体验。[学校原文](https://www.ynnu.edu.cn/info/1062/11702.htm)
2. 云南大学信息学院智能科学与技术系公开已有机器人、无人车、AI实验箱等教学科研设备。这可作为课程集成和实训服务的需求线索，不能据此推断新增采购预算。[学校原文](https://www.ise.ynu.edu.cn/directory/27/)
3. 昆明理工大学机电工程学院机器人工程介绍包含运动控制、感知与人机交互平台及机器人视觉教学。2020年的页面不代表2026年设备清单或最新采购需求。[学校原文](https://jdxy.kmust.edu.cn/info/1196/1911.htm)
4. 云南省2026年8月“人工智能+教育”方案提出企业真实项目参与实践教学。政策仅证明方向，不等于订单、补贴或供应商准入。[教育厅原文](https://jyt.yn.gov.cn/zfxxgk/zcwj/sjytwj/202608/t20260814_3698292.html)
5. 云南省商务厅2026-08-10资料显示斗南“花卉+文旅+数字”融合，已有文创花礼、花艺体验等业态。可支持花礼互动、花卉研学场景筛选，不能推断机器人付费转化。[商务厅原文](https://swt.yn.gov.cn/swxx/202608/t20260810_3733343.html)
6. 云南省商务厅2026-04-13公布斗南春节游客67.58万人次等市场统计。总客流不是某摊位可触达人数，更不是购买机器人体验的客户数。[商务厅原文](https://swt.yn.gov.cn/swxx/202604/t20260413_3217995.html)

## MVP假设

产品：云南花茶主题机器人实训与互动台。统一使用轻质、刚性、易夹持的标准包装物及卡片支架，游客选择主题后完成按单配物、放置、交付；学校把同一任务展开成视觉定位、遥操作、数据采集和动作学习课程。

首版不要求散乱鲜花整理、复杂包花、泡热茶或穿越人群。底盘先在隔开的两工位之间低速移动，展示时停车操作；如果客户不为移动能力付费，改为固定台面也可交付。双臂是教学和展示扩展，单臂可完成首个收费任务。

建议验证对象：熟悉的培训/研学组织者优先，其次学校STEM中心、花艺体验馆、景区室内文创店、品牌活动承办方。上述具体学校和斗南片区只是公开可核验线索，不表示已联络或合作。

## 仅用于验证的财务假设

机构活动服务：开发及准备投入30000元；每场服务收入3000元；每场人工、交通、耗材、维护等增量支出1500元；则每场贡献1500元，20场才能覆盖前期投入。不含税、销售管理费用、坏账和没有计入的机会成本；首场必须确认对方有权签约和付款。

游客单次付费：假设每次29元，材料8元、场地分成6元，则每次贡献15元；日运营支出500元。30次/日亏50元；50次/日余250元；80次/日余700元。覆盖30000元投入分别不可实现、约120个营业日、约43个营业日，且未含税费、淡旺季与返修停机。以上不是昆明市场报价，需实测支付转化和场地条款。

这说明首轮优先争取B端付费活动/课程包，游客逐单付费适合作为第二验证路线。不能用景区总游客量替代成交量，不能把机器人演示预算当成日常省人工预算。
