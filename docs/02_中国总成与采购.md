# 中国可购买的移动机械臂：总成、套件与采购判断

核验日期：2026-10-02，Asia/Shanghai。针对首轮总预算人民币 1–5 万元、首先接触昆明学校／培训／展厅／科研机构的场景。本次为官方公开资料核验，没有联系厂商、取得含税报价、下单或实机验收。

## 结论

中国已经可以买到三层产品：XLeRobot／LeKiwi 这类开发套件，LIMO COBOT 这类教学移动抓取整机，以及 COBOT MAGIC／星海图／睿尔曼这类研究总成。**“总成可以交付”与“替客户自动完成某项业务可以交付”是两项验收。** 目前最适合这笔预算的是先用 XLeRobot 做双臂演示和课程原型；如果客户更重视正规课程、建图导航和厂商支持，则询价 LIMO COBOT；若只需单臂、桌面以下小物抓取，LeKiwi 更简单。高端平台先借测、合作或询租，不宜依据宣传先买本体。

## 1. XLeRobot：国内复现路径最直接，但需把版本写进报价

官方仓库提供代码、硬件文件、仿真入口，顶层标注 Apache-2.0；可继续自行打印结构件、购买舵机并改装。底层舵机本身不因使用开源项目就成为开源硬件，各依赖仍按各自许可证处理。[项目仓库](https://github.com/Vector-Wangel/XLeRobot)

**旧报价不能直接用于今天采购。** 项目仍保留 2025 年 ¥3699／$579 套件公告，说明不含电池和宜家推车；自行采购表约 ¥3999 是自备电脑＋单 RGB 头部相机的基础成本。另有树莓派和深度相机增配。[价格表](https://github.com/Vector-Wangel/XLeRobot#-total-cost-)

WOWROBO 当前商店已称为 0.4.0，分为已装双臂套件、未装底盘扩展、组合包。页面显示 $349 起，同时有 sold out/unavailable 与“付款后3–7天发货”两种不同信号，因此现货状态不能确认。必须问到具体 SKU 和国内交货日期。[厂家销售页](https://shop.wowrobo.com/products/xlerobot-dual-arm-mobile-household-robot-kit)

官方 0.4.0 双轮装配页仍标注 under construction，作者说明舵机的速度、噪音、负载存在局限，升降结构的维护与稳定性也很难仅靠这类舵机解决。[双轮版本说明](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/assemble_2wheel.html)

软件有双臂、底盘、头部键盘／手柄遥操作；这是真实可阅读的工程入口。一次采购应约定能重复运行的 Git commit、依赖和校准文件，不能只写“支持 LeRobot／AI”。[遥操作教程](https://xlerobot.readthedocs.io/en/latest/software/getting_started/XLeRobot_teleop.html)

适合采购的理由：两只手有明显展览效果，课程可包含组装、校准、视觉、遥操作、示范数据。服务缺口：本次只核验到装配视频和制造支持，没有核验昆明上门安装、培训课时、响应时间或客户现场任务保修。能力边界见作者的[限制说明](https://xlerobot.readthedocs.io/en/latest/)；不能把网页的 600–1000g 当作我们的持续抓取承诺。

## 2. LeKiwi：更便宜、结构简单，适合单臂教学

官方仓库包含打印网格、CAD、URDF、BOM 与装配教程，顶层 Apache-2.0。标准路线是树莓派＋电脑、三轮全向底盘、SO101、环境相机和腕部相机。[LeKiwi 仓库](https://github.com/SIGRobotics-UIUC/LeKiwi)

矽递卖的是可选配的 12V 套件：必须逐项确认底盘、主从臂／单从臂、骨架打印件、计算机、SD卡、两路相机、电池、充电器与控制器。其销售页有“底盘含电池”的描述，而通用 Wiki BOM 将电池列为选配；这是 SKU 口径差异，不能靠产品标题推定全部包含。[当前选配页](https://www.seeedstudio.com/LeKiwi-Full-Kit-12V-Verision.html)、[官方2026目录](https://files.seeedstudio.com/wiki/wiki-platform/2026_Seeed_Studio_Catalog.pdf)

尤其需要注意：矽递中文教程明确说明采用 2025-06-05 前经过测试的 LeRobot 版本，并明确硬件质量负责范围，软件依赖问题可能转交 LeRobot 社区。因此买套件不等于买到长期的软件集成服务。[中文教程与责任范围](https://wiki.seeedstudio.com/cn/lerobot_lekiwi/)

中国采购入口有矽递官方淘宝企业店／天猫／京东渠道，但本次没有核验某个 LeKiwi SKU 在国内店的库存和含税价，应由官方给出国内链接。[矽递中国目录与渠道](https://files.seeedstudio.com/wiki/wiki-platform/2025_Seeed_Studio_Catalog_CN.pdf)

应用选择：低矮桌面或专用工位的轻物取放与移动，不要购买后才发现机械臂够不到标准教室桌面。声音交互也有厂商集成教程，可用于课程拓展；它并不能替代抓取成功率验证。[语音拓展示例](https://www.seeedstudio.com/blog/2026/05/20/add-voice-interaction-to-lekiwi-robot-with-respeaker-flex/)

## 3. LIMO COBOT：最值得和开源自组装正面比价的教学整机

松灵中文官网明确面向教育、竞赛与开发，配置 Orin Nano、激光雷达和深度相机，并列出 ROS2 课程、代码库、仿真模型、实验手册。底盘有四种运动模式；买时锁定雷达、相机、主控和软件版本。[官方中国产品页](https://www.agilex.ai/products/limo-cobot)

官方海外价格表为 $4,400；不能把它换算后直接当作昆明交付价。[官方价目](https://global.agilex.ai/collections/all)

**最容易误读的参数：4kg 是底盘运动载重，myCobot 280 M5 的机械臂负载只有250g、工作半径280mm。** 适合教学积木、小包装样品取放，不适合作为抓取水杯／大物件的高负载方案。[松灵构型说明](https://global.agilex.ai/products/limo-corot)、[大象机械臂官方规格](https://www.elephantrobotics.com/en/mycobot-280-m5-2023-specificatons-en/)

开放性是 ROS／Gazebo、Python／C++ 和公开驱动、模型／教学资料；本次没有证据认定它的完整机械、电气制造图纸全部开源。[松灵开发者中心](https://research.agilex.ai/)

相比套件，它已经是面向教学交付的产品路线；但整机导航抓取在买家环境的成功率、课程时长、上门培训、备件时效仍需写进合同。松灵有中国客服和售后渠道，这证明存在服务入口，不代表已承诺昆明服务等级。[松灵中国官网](https://www.agilex.ai/)

## 4. COBOT MAGIC：在国内复现 Mobile ALOHA 功能的直接成熟总成

当前中文产品页明确第二代采用 PiPER、TRACER 2.0、奥比中光相机与4060工控机，并提供主从双臂遥操作和模型训练／推理路线。厂商称已有50多家高校与科研机构使用；这是研究平台采用量陈述，没有给出50家商业自主作业现场。[官方产品](https://www.agilex.ai/page/690aef2d5e78cfa260412cb5)

PiPER 标准臂官方规格为 1.5kg 有效负载、626mm 工作半径，并有 Python、ROS1／ROS2、URDF 支持。不同年份经销页面出现509／610／626mm等数据，采购必须以所报型号与出厂配置单为准。[PiPER 中国官方规格](https://www.agilex.ai/products/piper)

公开资源包括 MIT 许可的 PiPER ROS 工作空间、Python SDK 和 ALOHA 仿真；固件版本还影响 URDF 坐标定义。上述证据只能证明控制栈开放，不能据此保证 TRACER／PiPER 全部机械图纸、固件源代码可自由制造。[PiPER ROS](https://github.com/agilexrobotics/Piper_ros)、[SDK](https://github.com/agilexrobotics/piper_sdk)、[ALOHA仿真](https://github.com/agilexrobotics/Mobile_aloha_sim)

整机国内没有核验到可靠公开含税价格。应问“研究平台包”和“指定任务集成包”两份报价，后者应含模型环境、示范数据、现场验收。首轮1–5万元不把它作为必买；可用于寻求高校已有设备合作或由厂家提供付费演示。

## 5. 星海图 R1 Lite：高性能对照，当前预算先考虑合作

官方海外销售页显示 $39,999，遥操作 R1 Lite-T／VR 和灵巧手不在标准包含项，且需联系业务采购。中国成交价没有在本次检索中核验。[销售页及包含项](https://galaxea-dynamics.com/products/galaxea-r1-lite-6-drof-general-mobile-manipulation-platform?variant=47296515342592)

2026文档明确单臂额定3kg@0.6m、峰值5kg@0.6m，整机96kg含电池；两臂A1X、G1夹爪、躯干可升降／前后移动。其2026尺寸与旧销售页不完全一致，应要求2026实发配置单，不能把不同代参数拼到一起。[2026官方规格](https://docs.galaxea-dynamics.com/R1Lite/docs/2026/)

软件提供 ROS2 Humble／Ubuntu22.04 驱动与控制接口；有双臂、躯干、底盘、相机、数采模块和技术支持入口。[ROS2开发文档](https://docs.galaxea-ai.com/Guide/R1Lite/software_introduction/ros2/R1Lite_Software_Introduction_ros2/)、[支持渠道](https://docs.galaxea-ai.com/)

这是一台可做二次开发的商用研究硬件，没有核验到全本体制造图纸开源。预算层面应要求租赁、联合案例、校企共享机时或厂商演示报价；本次没有核验任何一个官方的租赁价，不能承诺一定可租。

## 6. 睿尔曼双臂升降总成：操作空间和负载升级备选

官方产品页给出的构型是双RM65-B-V（可选RM75）、900mm升降、单臂5kg、视觉＋夹爪，整机约157kg，续航3–4h；这是厂商规格，没有在现场验证。[官方产品页](https://survey.realman-robotics.com/cn/products/dual-arm-lift.html)

官方论坛已有双臂总成使用手册，体现实物接线、启动和装配交付路径；平台定位包括教学、导航、视觉和双臂操作。[双臂总成手册](https://bbs.realman-robotics.cn/question/315.html)

官方提供 JSON／Modbus、多语言 SDK、ROS／ROS2和下载文档；这些开放接口可以降低集成难度，但不是整机硬件开源声明。[开发者资料](https://www.realman-robotics.com/en/main/developer-center.html)、[ROS2与MoveIt2入口](https://develop.realman-robotics.com/robot/ros2/getStarted/)

没有查到可核验的中国整机公开价格、昆明本地服务承诺或此产品的付费租赁价。仅在首批客户明确需要更高负载、多层货架操作、且愿承担升级预算后深入询价。

## 最值得询价的三个对象

1. **WOWROBO XLeRobot 完整可运行组合**：问0.3成熟方案与0.4双轮方案各一份报价，含电脑／树莓派、电池、车架、所有相机、校准和备件；问已装好到什么程度，当前现货与交期。优先用途：双臂展厅演示、遥操作课程、数据采集体验。
2. **松灵 LIMO COBOT 中国教学交付包**：请求含税、送达昆明、整机预装、课程资料授权、一次培训和备件价；先确认250g抓取能力能覆盖任务。优先用途：学校ROS2、SLAM、导航与视觉抓取课程。
3. **矽递 LeKiwi 12V 完整包**：问国内完整配置单，特别是是否含主臂／从臂、相机、树莓派、电池与打印件，软件支持边界和可运行镜像。优先用途：最低成本单臂课程和备用演示设备。

针对原版 Mobile ALOHA 的高配询价备选是 COBOT MAGIC，而不是直接照原论文跨境购买全部元件。

## 1–5万元内采购纪律与验收内容（建议，不是厂商报价）

- 一轮MVP只选一个主硬件路线。总预算1万元时，更适合个人开发和客户演示验证；外包开发、上门交付和持续售后很容易超过预算。
- 若预算3–5万元，建议先把硬件／传感器／电源／备件支出上限设为总预算的约35%–50%；剩余留给工装、调试、课程／界面、运输和现场支持。若选LIMO整机导致硬件超此比例，应缩小交付范围或让学校直接采购硬件，我们售课程与应用集成。
- 采购验收至少包括：开箱校准、遥操作可重复运行、数据录制／回放、50–100g标准物体取放、固定两工位移动后抓放、急停和人工接管、故障恢复、连续演示时温升／电量记录。以上重量是建议的初始测试条件，不是任何产品的认证负载。
- 目标任务写成：同一封闭演示区、同一种物品、两固定工位。厂商演示视频不能替代在目标台面高度、地面、照明下的验收。
- 问清保修对象：硬件故障、自己改装、开源代码升级失效、模型失败分别谁处理。要求可重装镜像／版本清单、离线运行方案、备件交期及远程支持渠道。

## 仍未确认的事项
